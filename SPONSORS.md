# Sponsors and support

TaskFlow is free and open source under the [MIT License](LICENSE). The demo is
self-funded and kept online for learning and portfolio purposes.

## Ways to support

- Star the repository and share it with someone building a task manager.
- Open a thoughtful issue with a reproduction, or review a pull request.
- Improve the docs, accessibility, tests, or performance.
- Sponsor the maintainer through [GitHub Sponsors](https://github.com/sponsors/Syed-Muhammad-Ali-Raza).

If GitHub Sponsors is not enabled for the maintainer account, the link will
show that sponsorship is unavailable; issues and pull requests are equally
valuable forms of support.

## Current sponsors

No sponsors are listed yet. If you would like to be acknowledged here, use
the GitHub Sponsors link above or email `syed.ali@taskflow.dev`.

## For teams

TaskFlow is a demo, not a managed service. For production work, fork the
repository, deploy it to your own Vercel and Neon accounts, and maintain your
own data and security controls. See [docs/DEPLOY_FREE.md](docs/DEPLOY_FREE.md).

Sponsorship is optional. The project and its documentation remain free to
read, use, fork, and improve.
